Cyber Defense Runner — Question Batch Validator

Paste a batch and validate it before merging. Nothing here touches the game files.
How to use this validator 
1. Paste a question batch into the box above (either a bare array, or
   `const NETWORKING_BASICS_QUESTIONS = [ ... ];`). Or click "Load .js file…".
2. Optionally type the Expected Topic (e.g. "Networking Basics") and the
   Expected ID Prefix (e.g. "networking-basics") to enforce those.
3. Click Validate. A PASS/FAIL banner plus full summary appears.

Checks performed:
  total count, unique IDs, required fields present, exactly 4 options,
  correct is integer 0-3, balanced A/B/C/D distribution, no obvious
  position pattern, no consecutive repeats (warning), no duplicate/near-
  duplicate prompts, no duplicate option text, topic match, valid tier,
  short explanations, no certification names, no empty strings, ID format.

Option-quality checks (ADVISORY warnings only, never block merge):
  - correct answer much longer than the average wrong answer
  - one option much longer than the others
  - three short options + one long definition-style option
  - the wrong options share an opening word the correct one does not
  - one/two-word distractors while the correct option is a full sentence

PASS means zero ERRORS. Warnings are advisory (distribution slightly off,
consecutive answers sharing an index, or any "OPTION QUALITY" smell) and
do not block merge.

Programmatic / Node CLI usage is documented at the top of
tools/validate-questions.js.
